# KrakenGram

Aplicación que usa **Lorem Picsum** para obtener imágenes y mediante JS se aleatorizan y filtran para mostrar en Inicio.

Se puede dar me gusta a las imágenes, estas se guardarán en el local storage como URL.

En la sección de favoritos aparecerán las imágenes que tuvieron un me gusta.

Para quitar una imagen de favoritos se debe dar click en el corazón rojo y un mensaje de confirmación aparecerá durante 2 segundos.
